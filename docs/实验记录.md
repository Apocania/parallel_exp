## 限制与复跑说明

1. 测试验证了有限故障序列，不等同于形式化证明；CRDT 收敛还依赖合法状态和充分传播。
2. 页面状态是多次独立读取，不是全局原子快照。
3. Docker 当前未在本机验证；验证路径是 Windows 本地 Python。
4. 迁移场景可在一半处暂停，也可使用新 D 数据库重复演示；旧数据库保留。
5. 正式报告建议在你们的展示机器上复跑，再记录自己的日期、配置与结果。
